常见问题

Package A 和 Package B 怎么选？

问自己一句：广告这件事，你想自己做，还是交出去？要结果、没时间，选 A，我们帮你开广告、调广告、做广告图。想掌握技能、预算有限，选 B，上一天线下实战课，之后三个月每周 Q&A 带着你做。

多久可以看到效果？

一般 7 天内上线。第 1 个月同时测多个角度，找出带来好 lead 的那个；第 2 个月把赢的角度放大；第 3 个月用成交数据反推，把赢的方法变成系统。

服务费包含广告费吗？

不包含。广告在你自己的广告账户里跑，广告费由你直接付给 Meta。账户和数据一直是你的，我们只是获授权帮你操作。

我还没有 Facebook Page、广告账户或 Pixel，可以开始吗？

可以。从 0 开始建 Page、Ad Account 和 Pixel，只是会比一般 7 天上线多几天。

为什么建议至少合作 3 个月？

因为 3 个月刚好是一个完整周期：测、放大、系统化。只跑一个月，通常刚找到赢的角度就停了。
